# 网球分析评估协议 v1

## 数据与冻结

首个自动能力晋级对象为固定机位、完整球场的手机单打。手机双打、广播单打和广播双打分别报告。
每个目标场景至少需要五场独立的原始测试比赛；这是最低采集门槛，置信区间过宽时增加比赛。
同一比赛的所有录像、裁剪、抽帧和增广必须属于同一 split。先分组，再选择模型与阈值。

训练集用于拟合，验证集用于调参和校准置信度，测试集只用于冻结后的比较。测试结果被用于选择
下一模型时，该测试集变为开发集；晋级需要新的未触碰测试比赛。
`tennis-ai benchmark` 会验证原始比赛分组、内容 SHA-256 和跨 split 的文件内容重复。
内容哈希不能发现转码或不同裁剪，原始 match_id 和采集记录仍然必要。

本仓库 `benchmarks/acquisition.json` 记录数据可用性，不包含视频、个人姓名或访问令牌。
实际 benchmark manifest、标签和预测保存在本地数据目录。每个 manifest 记录源文件摘要，模型
摘要、版本、参数、标注版本和冻结日期；公开报告只含聚合结果和不识别个人的来源类别。

## 标注单元

球：逐帧 visible / confirmed absent / unresolved；未标注和 unresolved 不作为负例。
球员：持久 participant_id、场景内 track_id、近远场角色、换边映射、脚点及可见性。
击球：接触时间区间、击球者、五类动作或 unknown、画面接触点、球员球场站位。
落点：确认触地时间区间、画面点、有效球场标定及米制坐标；遮挡和腾空球保持未知。
回合：有序击球 ID、边界及可选比分、发球者、胜负。胜负未知时禁用胜负条件统计。

标签必须声明已穷尽标注的时间范围，并涵盖无事件时间。第二位标注者独立标注每场至少一个
包含遮挡、远场与换边的片段；仲裁者记录分歧原因及最终值。模型输出不得作为独立标注答案。
联系时间报告区间重叠率和仲裁前中心时间误差；分类报告一致率/混淆矩阵，位置报告距离分布。

## 指标与晋级

| 能力 | 主指标与最低要求 | 必报补充项 |
|---|---|---|
| 球 | precision ≥0.90，recall ≥0.75 | near/far、正负样本、未标注率、观测/插值覆盖 |
| 球员 | 角色帧准确率 ≥0.98，ID switch ≤1/10 分钟 | 持久身份换边准确率、未知率 |
| 站位 | median ≤0.35 m，P95 ≤0.75 m | 标定有效覆盖、脚点方法、near/far |
| 接触 | F1 ≥0.85，median 时间误差 ≤2/30 s | 误差 P95、击球者准确率、拒答率 |
| 动作 | 五类 macro-F1 ≥0.80 | 每类 TP/FP/FN、支持数、unknown 比例 |
| 落点 | precision ≥0.90，median ≤0.5 m，P90 ≤1 m | 未关联/缺失位置、有效击球覆盖 |
| 回合 | precision/recall ≥0.90 | IoU ≥0.5 的一对一匹配，边界误差 |

球中心匹配沿用 1080p 高度下 6 像素容差，随画面高度缩放。事件匹配使用既有 0.1 秒容差；
接触时间误差另报，不能用宽匹配窗口掩盖定位误差。五种动作均需真值支持。
按原始比赛进行 2,000 次 bootstrap，固定 seed=0，报告 95% percentile 区间。
不足两场时区间不可估计；分母为零时报告 undefined，不填零。少量比赛的区间只作初步精度估计。
首版工具提供球 precision/recall 区间，其余区间实现前不得声称已经计算。

晋级必须满足点估计门槛，且区间下界支持 precision/recall 门槛；区间跨越门槛则继续收集
独立比赛。旧评估器的 phone_quality_passed 只代表旧门槛，不代表完整升级晋级。
模型、Core ML 和设备结果分别保存；无真实标签时 release_ready 必须为 false。

## 设备和用户验证

目标设备为 iPhone 15 Pro 或明确记录的等效设备。10 分钟 1080p30 分析 ≤20 分钟，
持续两小时无 OS 终止；记录峰值内存、系统 thermalState、每小时耗电和中断恢复。
首个 beta 采用峰值 resident memory ≤1.5 GiB、全程无 serious/critical thermalState、
分析耗电 ≤25 个百分点/小时作为工程预算，注明系统版本、初始电量、环境温度和屏幕状态。
设备预算调整必须先记录理由并重跑，不允许测完后悄悄改阈值。
验证飞行模式、旋转/VFR/音轨、低存储、后台挂起、导出播放和删除后无残余媒体。

教练卡须由两位有资质的教练独立评价：零无证据事实，至少 80% 获“有支持且可行动”评价；
试用球员至少 80% 能说出下一训练动作并找到依据。记录实际人数与分歧，不用 Agent 模拟评价。
